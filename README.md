# Advanced Dungeons And Dragons
### Creators: Dash Geiser, Rayne Robertson, Nick Grundman
This project aims to make the 1st edition Player's Guide to Advanced Dungeons and Dragons (1978) readable, both with tooltips over the text and a handy tool to sort through available characteristics when building a character. This information and the text will all be hosted on a GitHub Pages site right here on this repo.
